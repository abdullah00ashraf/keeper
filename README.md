# Keeper — Interactive 3D Sanctuary for Inaya Khan

A dedicated 3D interactive sanctuary featuring real-time WebGL/Three.js shaders, dual dynamic realms (The Koi Pond of Solace & The Northbound Ice Fjord Voyage), interactive audio synthesis, floating star lanterns, and custom ambient lighting.

## Deployment

Deployable instantly on Vercel with zero configuration:
- Root \/\ directly serves \index.html\ (Interactive 3D Realms).
- Clean URLs enabled via \ercel.json\.
